# Recruitment content

The homepage announcement links to `/join`. Recruitment copy is in `components/join-section.tsx`, with PhD opportunities first, followed by postdoctoral and undergraduate/master's opportunities. The page uses `app/recruitment.css` and the shared site header/footer.

The NSF funding logo is the unmodified official image downloaded from https://www.nsf.gov/themes/custom/nsf_theme/components/molecules/logo/logo-desktop.png. Logo source and usage guidance: https://www.nsf.gov/policies/brand. It acknowledges NSF support in the shared funding footer.
